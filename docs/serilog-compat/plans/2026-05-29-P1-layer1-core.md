# P1 — Serilog-Compat Layer-1 Core Call Surface Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Build the `MMP.Herald.Serilog` assembly (Layer 1 — source-compat, canonical impl): the Serilog-shaped `ILogger` interface + static `Log` facade (compat-only), the `LogEventLevel` enum and its bidirectional map to Herald `LogLevel`, message-template support including inline `{@}`/`{$}`, the **Serilog-hole-named arity generator** (separate from Herald's `[CallerArgumentExpression]` generator, over `LogPropertyCompact.From<T>`), and the **value-model mirror** (flat-fast / tree-on-demand: `Serilog.Events.LogEvent` + `ScalarValue`/`SequenceValue`/`StructureValue`/`DictionaryValue`) with **Jared's Guard 1** (architecture test) and **Guard 2** (0-B/op native-path benchmark row). Plus the cross-cutting fixtures the rest of the initiative reuses.

**Architecture:** `MMP.Herald.Serilog` is a thin canonical skin over Herald's already-zero-allocation engine. The static `Log` facade holds one mutable `Logger` slot and forwards to `StructuredLogger`'s fast path. The instance `Serilog.ILogger` is the Serilog-shaped port; its zero-alloc verbs are **generated**, not hand-written — a new `SerilogArityGenerator` emits `Verbose/Debug/Information/Warning/Error/Fatal` × arity 1..16, each binding the i-th positional arg to the i-th **template-hole** name (Serilog's naming rule), filling a stack `LogPropertyBufferN` via `LogPropertyCompact.From<T>` and calling `StructuredLogger.LogCompact`. `{@}`/`{$}` holes carry a non-default capture mode that the compact slot cannot represent, so those holes route **per-hole** to the full `LogProperty[]` path. The value-model mirror wraps a native `LogEvent` and projects properties to the Serilog tree **lazily, only when a custom extension reads them** — the native-sink hot path never instantiates it (Guard 1 + Guard 2 pin that structurally and by allocation).

**Tech Stack:** C# / .NET (`net9.0;net10.0` for the compat assembly — no net8 per the hard constraint), xUnit + FluentAssertions (`tests/Herald.OSS.Tests.csproj`), Roslyn incremental source generator (netstandard2.0, in `generators/`), BenchmarkDotNet net10 (`benchmarking/library/net10/`), real Serilog 4.3.1 (already in `Directory.Packages.props`) as the Layer-1 parity oracle. Inside Herald.OSS use `dotnet build` / `dotnet test` directly (the `build.sh` wrapper lives in the umbrella repo, not this fork).

**Assumes P0 landed:** levels are `verbose`/`debug`/`information`/`warning`/`error`/`fatal` (+ extras `notice`/`success`/`security`/`metric`); `KnownLogLevels.{Verbose,Information,Warning,Fatal}` and `KnownLogLevelKeys.{Verbose,Information,Warning,Fatal}` exist; typed verbs on `StructuredLogger` are `Information`/`Warning` with `Verbose`/`Fatal` added; the transitional alias map is **removed**. **Before starting P1, verify this** (Task 0, Step 0) — the current tree on `feat/serilog-compat` still shows pre-P0 names (`KnownLogLevels.Info`, generator `Levels = { "Trace","Debug","Info","Warn","Error" }`), so P1 is blocked until P0 merges.

**LogEventLevel ⇄ LogLevel map (authoritative — from Richard ADR + scope PRD §1):**

| `Serilog.Events.LogEventLevel` | Herald `LogLevel` (key) |
|---|---|
| `Verbose` | `KnownLogLevels.Verbose` (`verbose`) |
| `Debug` | `KnownLogLevels.Debug` (`debug`) |
| `Information` | `KnownLogLevels.Information` (`information`) |
| `Warning` | `KnownLogLevels.Warning` (`warning`) |
| `Error` | `KnownLogLevels.Error` (`error`) |
| `Fatal` | `KnownLogLevels.Fatal` (`fatal`) |

The map is **closed** over Serilog's six. Herald's four extras (`notice`/`success`/`security`/`metric`) have **no** `LogEventLevel` counterpart; the Herald→Serilog direction must report "no Serilog level" for them (it must not silently collapse them to a neighbour — that is G-LEVEL.4's sibling assertion, re-pinned here as G-VM-style negative).

```csharp
namespace MMP.Herald.OSS.Tests.TestSupport;

/// <summary>
/// Cross-cutting capturing-logger fixture for the serilog-compat suites.
/// Wraps the shipping <see cref="TestLogPipelineBuilder"/> (DRY — no new sink
/// type) and exposes the captured events as a live snapshot view.
/// </summary>
public static class TestLoggers
{
    public static (StructuredLogger Logger, IReadOnlyList<LogEvent> Captured) CreateCapturing<T>(
        LogLevel? minimumLevel = null)
    {
        var (logger, sink) = new TestLogPipelineBuilder()
            .WithMinimumLevel(minimumLevel ?? KnownLogLevels.Verbose)
            .Build();
        // GetEvents() returns a fresh snapshot list each call; the suites read it
        // after the act phase, so a thunk-backed view keeps the call sites terse.
        return (logger, new SnapshotView(sink));
    }

    private sealed class SnapshotView(InMemoryLogSink sink) : IReadOnlyList<LogEvent>
    {
        public LogEvent this[int index] => sink.GetEvents()[index];
        public int Count => sink.Count;
        public IEnumerator<LogEvent> GetEnumerator() => sink.GetEvents().GetEnumerator();
        System.Collections.IEnumerator System.Collections.IEnumerable.GetEnumerator() => GetEnumerator();
    }
}
```

```csharp
// src/Serilog/SerilogLevelMap.cs — single canonical bidirectional map (DRY)
#nullable enable
using System.Collections.Generic;
using MMP.Herald.Levels;
using MMP.Herald.Serilog.Events;

namespace MMP.Herald.Serilog;

public static class SerilogLevelMap
{
    private static readonly IReadOnlyDictionary<LogEventLevel, LogLevel> ToHeraldMap = new Dictionary<LogEventLevel, LogLevel>
    {
        [LogEventLevel.Verbose]     = KnownLogLevels.Verbose,
        [LogEventLevel.Debug]       = KnownLogLevels.Debug,
        [LogEventLevel.Information] = KnownLogLevels.Information,
        [LogEventLevel.Warning]     = KnownLogLevels.Warning,
        [LogEventLevel.Error]       = KnownLogLevels.Error,
        [LogEventLevel.Fatal]       = KnownLogLevels.Fatal,
    };
    private static readonly IReadOnlyDictionary<string, LogEventLevel> ToSerilogMap = BuildReverse();

    public static LogLevel ToHerald(LogEventLevel level) => ToHeraldMap[level];

    public static bool TryToSerilog(LogLevel level, out LogEventLevel result)
        => ToSerilogMap.TryGetValue(level.Key, out result);

    private static IReadOnlyDictionary<string, LogEventLevel> BuildReverse()
    {
        var d = new Dictionary<string, LogEventLevel>();
        foreach (var kv in ToHeraldMap) d[kv.Value.Key] = kv.Key;  // closed over the six
        return d;
    }
}
```

### Task 4: The Serilog-hole-named arity generator (golden test FIRST, then generator)

```csharp
using System.Threading;
using MMP.Herald.Serilog.Events;

namespace MMP.Herald.Serilog;

public static class Log
{
    private static ILogger _logger = SilentLogger.Instance;

        => Logger.ForContext(name, value, destructure);

    {

        (current as IDisposable)?.Dispose();
```
