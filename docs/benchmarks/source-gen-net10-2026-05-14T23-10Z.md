# Source-gen head-to-head — net10

Three libraries' source-gen logging paths on the same template plus
four typed arguments.

## Host

\`\`\`
BenchmarkDotNet v0.14.0, Windows 11 (10.0.26200.8246)
12th Gen Intel Core i9-12900K, 1 CPU, 24 logical and 16 physical cores
.NET SDK 10.0.203
  [Host]     : .NET 10.0.7 (10.0.726.21808), X64 RyuJIT AVX2
\`\`\`

## Setup

Each library declares the same logging method via its source-gen attribute:

\`\`\`csharp
[HeraldLog(Level = "info", Category = "App",
    Message = "User {userId} purchased {sku} for {price} at {timestamp}")]
public static partial void Purchase(StructuredLogger logger,
    int userId, string sku, double price, string timestamp);

[ZLoggerMessage(LogLevel.Information,
    "User {userId} purchased {sku} for {price} at {timestamp}")]
public static partial void PurchaseZ(ILogger logger,
    int userId, string sku, double price, string timestamp);

[LoggerMessage(Level = LogLevel.Information,
    Message = "User {userId} purchased {sku} for {price} at {timestamp}")]
public static partial void PurchaseMel(ILogger logger,
    int userId, string sku, double price, string timestamp);
\`\`\`

Sinks: Herald → \`WithNullSink()\`. ZLogger →
\`AddZLoggerStream(Stream.Null)\`. MEL → active-null provider
(formatter callback runs, output discarded).

## Results

| Method | Mean | Allocated |
|---|---:|---:|
| Herald \`[HeraldLog]\` | 26.73 ns | — |
| ZLogger \`[ZLoggerMessage]\` | 145.32 ns | 7 B |
| MEL \`[LoggerMessage]\` | 171.89 ns | 232 B |

## Reading the table

- Herald is fastest by 5.4x over ZLogger and 6.4x over MEL.
- Herald allocates zero per call. The \`[HeraldLog]\` generator emits
  \`LogPropertyCompact.From<T>(name, value)\` for each property; the
  factory's JIT-specialized per-T body stores primitive values
  (\`int\`, \`double\`, \`bool\`, \`DateTime\`) directly in
  \`LogPropertyCompact.ScalarBits\` with no box. Strings land in
  \`RefValue\` without allocation.
- ZLogger's 7 B is residual struct copy overhead BDN's counter
  picks up; ZLogger's source-gen path is also essentially zero-alloc.
- MEL's 232 B is the state struct plus \`KeyValuePair\` array MEL's
  generator emits for the formatter callback.
